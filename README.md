# IP Profile 🌍

A fast, clean, and accurate tool to track and locate any IP address globally. Get instant geolocation, ISP, and network details.

**[🔴 Live Demo Here](https://advaya.pages.dev/ip-profile)** *(Update this link if you host it elsewhere)*

---

## Features

*   **🔍 Instant IP Lookup:** Find details of any public IP address instantly.
*   **🗺️ Interactive Mapping:** Smooth map fly-to animations using Leaflet.js and Esri Dark Gray base maps.
*   **🏢 Detailed Telemetry:** Displays IP Address, City, Country, and Internet Service Provider (ISP).
*   **📱 Fully Responsive:** Works perfectly on desktop, tablet, and mobile screens.
*   **⚡ Lightweight:** Built with pure Vanilla JS, no heavy frontend frameworks.

---

## 🛠️ Tech Stack

*   **HTML5 & CSS3** (Custom Dark SaaS UI)
*   **Vanilla JavaScript (ES6)**
*   **Leaflet.js** (For interactive map rendering)
*   **IPAPI** (Free API for IP geolocation data)
